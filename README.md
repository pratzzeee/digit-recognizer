# Handwritten Digit Recognition with TensorFlow (MNIST)

This project implements a simple **digit recognition model** using the [MNIST dataset](http://yann.lecun.com/exdb/mnist/).  
The model is built with **TensorFlow/Keras**, trained on handwritten digits, and can also predict digits from custom images.

---

## 🚀 Features
- Trains a neural network on the MNIST dataset.
- Evaluates model accuracy on test data.
- Accepts a custom image (`digit.png`) and predicts the digit.
- Visualizes digits and predictions using Matplotlib.
